# A01 Understanding Development Environments and Tools for Edge AI and IoT

## Assignment Summary
This assignment focuses on developing a clear understanding of the core tools used in Edge AI and IoT development. The task requires researching six tools, explaining their purpose, describing their functionality, identifying typical use cases, and providing illustrative examples. The final deliverable is a structured report that demonstrates comprehension of how these tools support the Edge AI and IoT workflow.

## Learning Objectives
The assignment is designed to support the following learning outcomes:

1. Build foundational knowledge of development environments used in Edge AI and IoT projects  
2. Understand how tools support data collection, model training, deployment, and device integration  
3. Recognize the workflow from coding to real time data handling to on device inference  
4. Analyze practical examples that demonstrate how each tool functions in real world scenarios  
5. Strengthen the ability to communicate technical concepts clearly and accurately  

## Tools Covered in the Assignment

### Visual Studio Code
The assignment requires describing Visual Studio Code, explaining its purpose, and identifying typical use cases.  
The uploaded document explains that Visual Studio Code is a cross platform editor that supports multiple languages, debugging, Git integration, and remote development. One excerpt states that it enables “remote development on devices, including SSH and containers” which is essential for edge workflows.

### Node.js
The assignment requires describing Node.js, explaining its purpose in server side scripting, and identifying typical use cases.  
The document notes that Node.js is event driven and non blocking, making it suitable for “real time IoT gateways and dashboards” that communicate through protocols such as HTTP and MQTT.

### Edge Impulse CLI
The assignment requires describing the Edge Impulse command line interface, explaining its purpose in edge machine learning, and identifying typical use cases.  
The document states that the CLI supports “streaming sensor data from devices into a dataset pipeline” and enables automated data uploads and on device testing.

### TensorFlow and TensorFlow Lite
The assignment requires describing both frameworks, explaining their roles in training and deployment, and identifying typical use cases.  
The document explains that TensorFlow is used for training models while TensorFlow Lite is used for optimized inference. One excerpt notes that TensorFlow Lite produces models that are “smaller and faster” for edge devices.

### Google Colab
The assignment requires describing Google Colab, explaining its purpose in cloud based development, and identifying typical use cases.  
The document highlights that Colab provides “access to accelerators such as GPUs” and supports preprocessing, training, evaluation, and exporting in a collaborative notebook environment.

### Generative AI Coding Tools
The assignment requires describing generative AI coding tools, explaining their purpose, and identifying typical use cases.  
The document states that these tools support “AI assisted code completion and debugging” and can generate tests, explain unfamiliar code, and assist with implementation.
